# Security policy

## Reporting a vulnerability

Please report security problems privately to **security@owlpane.com**. Do not open a public issue.

Include what you found, the version or commit, and steps to reproduce. We aim to acknowledge a report within 3 working days and to tell you what we plan to do within 10 working days. We will credit you in the release notes if you want that.

## Scope

The Owlpane agent for Kubernetes (this Helm chart and its images): for example excess RBAC permissions, data the collector ships that it should not, or unsafe defaults.

Out of scope: social engineering, denial-of-service testing against hosted services, and findings that need a compromised device or cluster admin rights.

## Supported versions

Only the latest release receives security fixes.
